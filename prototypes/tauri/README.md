# Tauri packaging spike

This is a packaging boundary, not a second mailbox implementation. The Tauri shell will launch the loopback helper and display its UI after the workflow wins real-user validation. Rust/Tauri is not installed in the current environment, so no compiled-binary claim is made.

Required before activation: signed IPC allowlist, CSP, updater public key, macOS entitlements/notarization, Windows signing, installer/uninstaller, and real native-adapter E2E.
